# EcosistemaLogisticoUNI-V_2.0
Ampliación del Ecosistema Logístico Inteligente mediante CRUD (Create, Read, Update, Delete), Expresiones Lambda y Streams en Java.

Este proyecto consiste en la ampliación del proyecto de EcosistemaLogisticoUNI, se aplicaron mejoras en las clases, métodos y variables usando Lambda y Streams.
Esta version 2.0 se ha realizado para mejorarlo siguiendo los patrones del CRUD.

# Estructura del Proyecto
El sistema se basa en los siguientes pilares de la POO:
1. **Abstracción:** Uso de la clase abstracta `Vehiculo` y la interfaz `IConectable`.
2. **Herencia:** Clases `CamionAutonomo`, `DronTransporte` y `MotoDelivery`.
3. **Polimorfismo:** Procesamiento dinámico de la flota mediante el método `monitorearFlota()`.
4. **Encapsulamiento:** Atributos privados con métodos de acceso controlados.
5. **Sobreescritura de metodos:** Métodos sobreescritos desde la clase abstracta `Vehiculo`.
